## 5. التحذيرات الذكية (Smart Alerts Engine)

### قواعد التنبيه التلقائية

```javascript
// Alert Rules Engine
NEXORA.Alerts = {
  rules: [
    {
      id: 'budget_overrun',
      name: 'تجاوز الميزانية',
      condition: (project) => {
        const cost = H.projCost(project.id);
        return cost > project.budget * 0.9; // 90% threshold
      },
      severity: (project) => {
        const ratio = H.projCost(project.id) / project.budget;
        if (ratio > 1.0) return 'critical';  // 🔴
        if (ratio > 0.95) return 'high';     // 🟡
        return 'medium';                       // 🟢
      },
      message: (project) => `تجاوز الميزانية: ${project.name}`,
      action: 'navigate://costs'
    },
    {
      id: 'schedule_delay',
      name: 'تأخر الجدول الزمني',
      condition: (task) => {
        const a = DB.assignments.find(x => x.task_id === task.id);
        return a && a.due_date && new Date(a.due_date) < new Date() && task.status !== 'done';
      },
      severity: 'high',
      message: (task) => `تأخر: ${task.title}`,
      action: 'navigate://gantt'
    },
    {
      id: 'quality_issue',
      name: 'مشكلة جودة',
      condition: (task) => task.approved === false,
      severity: 'critical',
      message: (task) => `مرفوض: ${task.title}`,
      action: 'navigate://approvals'
    },
    {
      id: 'resource_shortage',
      name: 'نقص الموارد',
      condition: () => {
        const activeTasks = DB.tasks.filter(t => t.status === 'in_progress');
        const available = DB.employees.filter(e => e.active);
        return activeTasks.length > available.length * 3; // 3 tasks per employee
      },
      severity: 'medium',
      message: () => 'الموارد غير كافية للأعمال الجارية',
      action: 'navigate://employees'
    }
  ]
};
```

### سبب اختيار Vanilla JS (لا React/Vue/Angular)

1. **لا Build Step** — تعديل مباشر على GitHub بدون CI/CD
2. **أداء فائق** — ملفات صغيرة (الكود < 200KB)
3. **PWA مثالي** — Service Worker يخزن كل شيء محلياً
4. **عمل بدون إنترنت** — IndexedDB يكفي للعمل الميداني
5. **صيانة سهلة** — أي مطور يفهم الكود بدون Frameworks
